# 五子棋人机对弈 - 微信小程序版

HTML5五子棋AI对弈的微信小程序版本，支持三档AI难度、双人对战。

## 功能特性

- **三档AI难度**：低级（随机+防守）、中级（启发式评估）、高级（Minimax+Alpha-Beta剪枝）
- **双人对战模式**
- **19×19标准棋盘**
- **胜利判定**：四方向连珠检测
- **悔棋功能**
- **最后一手标记**
- **胜利连线高亮**

## 项目结构

## 使用说明

### 1. 导入微信开发者工具

1. 下载安装微信开发者工具
2. 选择"导入项目"
3. 项目目录选择 `gomoku-miniprogram`
4. AppID 可使用测试号或填写自己的AppID
5. 点击"确定"导入

### 2. 编译运行

- 导入后自动编译
- 在模拟器中预览效果
- 可扫码在真机上预览

### 3. 发布上线

1. 在微信开发者工具中点击"上传"
2. 填写版本号和项目备注
3. 登录微信公众平台
4. 在"版本管理"中提交审核
5. 审核通过后发布

## AI难度说明

| 难度 | 算法 | 特点 |
|------|------|------|
| 🟢 低级 | 随机+概率防守 | 会漏防，适合初学者 |
| 🟡 中级 | 启发式评估 | 攻防均衡，必堵四连 |

## 技术要点

### Canvas绘制
- 使用Canvas 2D API（`type="2d"`）
- 支持高清屏适配（`pixelRatio`）
- 手动管理绘制状态

### 事件处理
- `bindtouchstart`：落子
- `bindtouchmove`：悬浮预览（可选）
- `bindtouchend`：结束交互

### AI算法
- 与HTML5版本保持一致
- 三档难度渐进式实现
- 支持Alpha-Beta剪枝优化

## 注意事项

1. **Canvas尺寸**：固定640x640px，小程序中需考虑屏幕适配
2. **事件坐标**：使用`e.touches[0].x/y`获取Canvas内坐标
3. **高性能绘制**：避免频繁`setData`，直接操作Canvas上下文
4. **真机测试**：部分API在模拟器和真机表现可能不同
