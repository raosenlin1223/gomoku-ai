# ♟ 五子棋人机对弈 Gomoku AI

基于 HTML5 Canvas 的五子棋人机对弈游戏，支持三档 AI 难度。

## ✨ 功能特性

- **19×19 标准棋盘**，黑白双色棋子
- **三档 AI 难度**：
  - 🟢 **低级**：随机落子 + 概率防守（70% 堵四连，50% 堵活三）
  - 🟡 **中级**：启发式评估，棋型打分（活四/冲四/活三/眠三/活二等），攻防权重
  - 🔴 **高级**：Minimax 搜索 + Alpha-Beta 剪枝，深度 2~4 层自适应，候选剪枝优化
- **双人对战模式**：支持两人本地对战
- **完整游戏功能**：胜利判定 + 连线高亮、悔棋、重新开始、悬浮预览、最后一手标记、平局检测

## 🎮 玩法说明

1. 选择对战模式（双人对战 / 人机低级 / 人机中级 / 人机高级）
2. 点击「应用设置」开始
3. 玩家执黑先行，AI 执白
4. 点击棋盘交叉点落子
5. 五子连珠即获胜

## 🤖 AI 算法说明

| 难度 | 算法 | 搜索深度 | 候选剪枝 | 特点 |
|------|------|---------|---------|------|
| 低级 | 随机 + 基础防守 | 0 | 无 | 会漏防，适合新手 |
| 中级 | 启发式评估 | 1（贪心） | 评估排序 | 攻防均衡，不会漏堵 |
| 高级 | Minimax + α-β | 2~4 | Top 8~12 | 远见布局，能识破双三威胁 |
